# final

### Описание:
Проект предоставляет возможность преподавателям (пользователям), в зависимости от их графика и пожеланий добавлять, редактировать и удалять личные события в расписании.

### UI тесты (`@pytest.mark.ui`):
1. Создание события с сегодняшней датой
2. Создание события со вчерашней датой
3. Создание 2 событий в одном временном слоте
4. Создание события зеленого цвета
5. Создание короткого события

### API тесты (`@pytest.mark.api`):
1. Получить список событий
2. Создать событие длиной в 10 часов
3. Изменить название и описание события
4. Удаление события
5. Создание события без названия

### Стек:
* Python 3.14+
* pytest
* selenium
* requests
* allure-pytest

###  Шаги для запуска проекта

#### 1. Склонировать проект
```bash
git clone https://github.com/SemyonGorev/final.git
cd final
```

#### 2. Установить все зависимости из файла requirements.txt
```bash
pip install -r requirements.txt
```

### Команды для раздельного запуска тестов

Вы можете запускать UI и API тесты раздельно или вместе с помощью встроенных маркеров pytest:

#### Запуск ТОЛЬКО API тестов:
```bash
pytest -m api
```

#### Запуск ТОЛЬКО UI тестов:
```bash
pytest -m ui
```

#### Запуск ВСЕХ тестов в проекте разом:
```bash
pytest
```

### Работа с Allure отчетами

При запуске тестов результаты автоматически сохраняются в папку `allure-results` (настройка прописана в файле `pytest.ini`).

#### Сгенерировать и сразу открыть отчет в браузере:
```bash
allure serve allure-results
```

#### Альтернативный способ (Ручная генерация статического отчета):
1. Сгенерировать файлы отчета в папку `allure-report`:
   ```bash
   allure generate allure-results --clean -o allure-report
   ```
2. Открыть готовый отчет:
   ```bash
   allure open allure-report
   ```
